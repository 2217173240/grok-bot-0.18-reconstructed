## 保留的容量与版本边界

- 审计 outbox 保留已接受的待转发事件，2000 条为单次越界告警阈值；发送成功后清理。后端开关读取失败时保留本地 JSONL 并报告，事件不进入转发队列。发送确认与文件保存之间退出可能重复投递，事件保留原 eventId；没有跨后端事务的恰好一次保证。
- Episode 队列保留失败批次，每回合最多处理一个配置批次，interval 接受 1–64 的整数。持续失败会增加保留数据量；处理错误会报告，工具执行不会因记忆维护失败自动重放。

- 请求 ID 持久历史保留最近 200 条。当前错误关联使用最新 ID，当前回合另有内存记录；未发现该上限影响执行正确性。
- memory synthesis 的待处理证据是后台内存队列，超限已有 `dropped` 报告；完整对话保存在 transcript。它与决定消息补发的权威状态分别管理。
- 结构化日志运行期超限已有 `overflow_evicted` 计数与 `dropped` 通知；只核对 checkpoint 恢复的实际缺口。
- 当前支持 macOS arm64、固定 Electron 42 与 AI SDK v4。升级时验证 safeStorage、SDK 工具/流/用量、原生模块和 CLI 入口；不在本轮引入跨平台重写或大版本迁移。
- 开发构建使用 Node 26.5.0；容器 Node 22.23.2 的兼容范围由实际容器门禁验证。版本差异与 experimental 警告单独记录，不能直接当作运行失败。
- 模型默认值可覆盖；配置可读性错误必须在请求 API 前报告。模型可用性仍由具体 provider 与账号决定。

## 保留的验收条件

- local admin 的通用密钥存储当前仍有 #71 所述重启覆盖缺陷。此前 Claude 使用独立 token 文件的成功回合，不覆盖 Settings 中通用密钥的重启持久化；该项在修复验收前保持未完成。
- 运行凭据、浏览器 cookie/profile、用户数据卷不得进入 Git 或构建上下文。两个仓库分别执行历史秘密扫描，报告全量遮蔽匹配内容；源码发布检查拒绝已跟踪的凭据与会话路径。扫描通过只覆盖对应规则与输入，不能作为任意内容安全的证明。

- OpenRouter、Command Code 有效账号回合仍需用户提供已配置账号；Command Code 的真实无效密钥路径已验证。
- Codex 仅在隔离容器只读使用现有凭据；本轮不将账号目录挂入生产容器。
- passkey、真人登录与交回需用户提供测试站点并参与；自动化路径的通过不覆盖这些操作。
- 公开分发原版资源继续遵循 PROVENANCE.md；当前复用固定构件的目标保持不变。
- 桌面模式的容器隔离、浏览器自身沙箱、workspace bind 与出口控制分别审查。应用层网络 guard 无法替代出口防火墙。
- 历史改动与原始验证记录保存在 Git 历史及对应专题文档；当前工作状态以本页和架构文档为准。
