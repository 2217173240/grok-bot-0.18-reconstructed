## 验证边界

测试使用真实文件、目录、文件替换及大小限额。Windows 工作流执行本轮通用行为测试，POSIX 专有链接检查明确标记适用平台。

同一文件句柄保证检查与读取针对同一对象；固定读取范围限制内存和字节数。POSIX `O_NOFOLLOW` 拒绝打开末级符号链接。上述措施不提供祖先目录并发替换的原子保护，也不保证有写入权限的进程无法在同一 inode 内改写内容。Windows 的路径身份比较只覆盖观察到的替换，不宣称具备 POSIX 的原子链接拒绝能力。

保留 `extended` 查询与 `remote_and_local` 威胁模型。本轮不增加目录、规则或全局排除项；后续扫描若新增告警，仍按对应路径和实际操作逐项审查。
