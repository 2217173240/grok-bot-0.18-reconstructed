## 实施的修正

- `DISPLAY` 通过独立 argv 进入固定 Bash 程序，命令替换和引号不再成为脚本内容。
- workflow、MCP 配置与运行定义、source map 使用安全字典，保留合法特殊名称，防止继承字段影响解析。
- 附件和开发 store manifest 检查实际路径，拒绝预置符号链接越过明确的存储目录。附件在同一已打开句柄上检查类型、大小并按固定范围读取，POSIX 拒绝末级链接替换；显式导入任意来源文件的功能保留。
- Codex 凭据通过已检查的文件句柄读取；POSIX 使用 `O_NOFOLLOW`，Windows 保留打开前后身份比较。WAL 在实际打开的句柄上检查身份、大小及尾部后写入。
- 状态标志和升级文件用随机、排他创建的临时文件发布，保持原有最终路径、内容、权限及 bundle 先于 command 的顺序。Profiler 拒绝直接目录链接，以随机文件名、`wx` 和 `0600` 写入。
- PowerShell 每次执行使用独立私有目录，保留 BOM 和状态传递，正常结束、错误及取消路径清理自有目录。
- `.sandignore` 使用已有 RE2JS 进行线性匹配。常见 glob、顺序否定和目录剪枝行为保留；`?` 按 Unicode 字符匹配，结束锚点匹配完整路径，`[]a]`、`[!]]` 遵循 RE2 字符组语义。相应边界有明确测试。

测试使用真实文件、符号链接、Bash、生产解析函数和 inspector 采样。Windows 工作流执行真实 PowerShell 的正常运行、状态继承、取消及清理测试；缺少运行环境的本机测试明确跳过。此验证不等同于已在所有部署环境复现攻击。
